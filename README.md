# Setlister pro Home Assistant

Repozitář obsahuje Home Assistant add-on **Setlister** pro správu repertoáru, skládání setlistů a tisk individuálních poznámek členů kapely.

## Instalace z repozitáře

1. V Home Assistantu otevři **Nastavení → Doplňky → Obchod s doplňky**.
2. V nabídce **Repozitáře** přidej adresu tohoto GitHub repozitáře.
3. Nainstaluj **Setlister**, zapni automatický start a spusť ho.
4. Otevři webové rozhraní na portu `8110`.

Data jsou uložena v trvalém adresáři `/data` add-onu a zahrnuta do záloh Home Assistantu.

Podrobná dokumentace je v [setlister/DOCS.md](setlister/DOCS.md). Přehled změn všech publikovaných verzí najdeš v [RELEASE_NOTES.md](RELEASE_NOTES.md).
